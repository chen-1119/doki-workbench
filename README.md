# Doki 工作台

Doki 把图文和视频素材整理成发布任务。网页工作台负责草稿、排期和记录，Chrome 插件负责取任务、下载素材、打开创作者后台、预填文案和回填作品链接。

## 从仓库启动

安装 Node.js 22.13+ 和 Chrome 120+。克隆仓库或下载源码后，在仓库根目录运行。

```bash
npm start
```

打开 [Doki 工作台](http://127.0.0.1:8794/)。项目只用 Node.js 内置模块，无需运行 `npm install`。Windows PowerShell 若拦截 `npm.ps1`，运行 `npm.cmd start`，或直接执行 `node src/server.mjs`。

1. 在 Chrome 打开 `chrome://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择本仓库的 `extension/` 文件夹。
2. 点击工作台「连接 Chrome 插件」并复制配对信息。打开 Doki 插件，粘贴并连接。使用同一 Chrome 在平台后台自行登录。
3. 新建图文或视频，填写文案和排期，添加素材，再点「加入发布队列」。也可以通过 CLI 或 Skill 建任务。
4. 插件中选择任务并打开后台，选择下载的素材上传。编辑器出现后，重新打开插件并点「预填当前页面」。预填失败时使用插件的复制按钮。
5. 核对内容、封面和平台声明，在创作者后台点击发布或定时发布。确认交接后，等作品可查看，再把链接回填到工作台。

## 发布入口

| 平台 | 图文 | 视频 | 交接方式 |
|---|---|---|---|
| 小红书 | 支持 | 支持 | 分别打开图文与视频入口，选入文件后尝试预填 |
| 抖音 | 支持 | 支持 | 打开创作者中心，手选图文或视频入口 |
| B 站 | — | 支持 | 打开创作中心视频投稿入口 |
| 视频号 | — | 支持 | 打开视频号助手，选入视频并补齐平台要求 |
| YouTube | — | 支持 | 打开 Studio，再开始上传 |

「支持」指工作台可建任务、校验素材、排队并在插件提供下载与交接。预填以当时页面实际识别结果为准。使用浏览器原生文件选择器上传。标题、正文和话题文本可以独立复制。实际定时、最终发布和状态确认在平台完成。工作台在队列展示计划时间。

## 用 Codex 准备任务

在本仓库根目录开启 Codex 会话后调用 `$doki-publish`。

> 使用 $doki-publish，把这一组图片整理成小红书图文草稿，保留原图顺序。

Skill 已放入仓库的 `.agents/skills/doki-publish/`。未识别仓库级 Skill 的环境可以将该目录放到客户端支持的 Skills 目录，并在 Doki 仓库根目录运行命令。

```bash
npm run doki -- import path/to/任务.json
npm run doki -- import path/to/任务.json --queue
npm run doki -- status <任务ID>
```

图文、视频清单、素材限制、状态和故障处理见 [完整发布流程](docs/workflow.md)。

## 本地数据与验收

默认数据存于 `data/`，包含 SQLite、素材和插件配对码。发布素材和数据库遵循 `.gitignore`。这个版本用于一台电脑上的个人工作台，服务只监听 `127.0.0.1`。可用 `DOKI_PORT` 和 `DOKI_DATA_DIR` 自定义端口与数据路径。更换数据目录或重置配对码后重新连接插件。备份前先关闭服务，再复制整个数据目录。

```bash
npm test
```

自动化测试覆盖图文和视频素材上传、队列校验、插件配对、交接、链接回填、CLI 导入及持久化。真实平台的发布验收步骤见 [完整发布流程](docs/workflow.md#平台验收)。
