# Doki 完整发布流程

## 1. 准备任务

一个平台、一种内容类型对应一条任务。多平台转载分别填写标题、正文、话题，方便每条作品有自己的状态和链接。

| 内容 | 准备项 | 校验 |
|---|---|---|
| 图文 | 标题、正文、话题、按顺序排列的正文图。第一张用作首图 | JPG、PNG、WebP，1–18 张，每张最多 25 MB |
| 视频 | 标题、正文、话题、成片，可选封面 | MP4、MOV、WebM，成片最多 2 GB。封面用 JPG、PNG 或 WebP |

以上大小和数量是 Doki 的本地上限。上传时同时遵守实际平台的规则。小红书标题在入队时限制为 20 字符。图文显示顺序以添加顺序为准。桌面上传时可逐张选择或选完后在平台预览顺序。

## 2. 在工作台创建或导入

网页上通过「新建内容」上传。使用 Codex 或脚本时，每条导入清单为 UTF-8 JSON，素材位置相对于清单，放在同目录或子目录。需要修改正文时可以改草稿，不改变任务 ID。

### 图文清单

```json
{
  "platform": "xhs",
  "kind": "images",
  "title": "AI订阅失败先查这3项",
  "body": "准备付款前，先核对账号地区、付款渠道与当前订阅状态。",
  "tags": "AI订阅 订阅避坑",
  "images": ["assets/01-cover.png", "assets/02-checklist.png"]
}
```

### 视频清单

```json
{
  "platform": "bilibili",
  "kind": "video",
  "title": "用同一组任务实测两款 AI 模型",
  "body": "同一批输入对比长文理解、代码修改和图片识别。",
  "tags": "AI模型 实测",
  "video": "assets/final.mp4",
  "cover": "assets/cover.jpg",
  "scheduledAt": "2026-12-01T20:00:00+08:00"
}
```

平台值为 `xhs`、`douyin`、`bilibili`、`channels`、`youtube`。在网页录入时间按电脑时区显示。清单中排期可省略，填写时带时区。素材被完整复制到工作台数据目录，原文件由使用者管理。

```bash
npm run doki -- import path/to/任务.json
npm run doki -- queue <任务ID>
npm run doki -- list
```

导入过程如果失败，按 CLI 输出的 ID 运行 `npm run doki -- import path/to/任务.json --resume <任务ID>`。工作台会检查已导入的素材清单，再继续剩下的文件。网页上传失败时草稿保留已成功的素材，重新选择失败的文件即可。

## 3. 插件交接

1. 在 Doki 插件选择队列任务，按顺序下载图片或下载视频和封面。手里已有同样素材时可直接用原文件。
2. 打开创作者后台，确认当前账号。图文选图文入口，视频选视频入口。选择素材并等待编辑表单出现。
3. 在同一个标签页点击工具栏 Doki，选择正确任务，再点击「预填当前页面」。插件尝试填写标题和正文，并反馈回读结果。已有文字会保留，页面改版或字段不明确时可改用手动粘贴。
4. 检查平台的可点击话题、封面比例、声明、可见范围、定时和最终预览。点击「确认已交接」，再在平台按需要提交。
5. 定时或审核中保持「待回填」。作品可见后，复制平台分享链接，在插件或工作台选择「记录已发布」。视频号没有可复制链接时支持人工确认，其他目标要求作品链接。

## 4. 看状态与恢复

| 状态 | 意义 | 下一操作 |
|---|---|---|
| 草稿 | 文案和素材正在准备 | 编辑、添加素材或加入队列 |
| 待交接 | 已通过本地检查 | 从插件取任务，核对素材和编辑器 |
| 待回填 | 已确认交接，等待实际作品 | 审核或定时完成后回填 |
| 已发布 | 已记录作品链接，或视频号已人工确认 | 从归档查看作品 |

发现素材或排期需要改时，在工作台退回草稿。若已经在平台提交过，先在平台检查该稿件状态，避免重复投稿。工作台与插件会在打开或主动刷新时取得最新状态。

| 现象 | 处理方法 |
|---|---|
| 插件连接不上 | 确认 `npm start` 正运行，工作台地址使用 `127.0.0.1`，重新复制配对信息 |
| 找不到文件 | 回工作台检查素材是否上传成功，插件会保留下载按钮 |
| 找不到标题或正文 | 先选入素材并等待平台编辑器出现，回到该标签页再打开插件。也可分别复制后粘贴 |
| 发布链接无效 | 从作品的分享菜单或公开作品页重新复制当前平台的 HTTPS 链接 |
| 更改文案或发布类型 | 在草稿状态修改。切换图文与视频类型前移除旧类型素材 |

## 平台验收

1. 用两张无敏感信息的图片建一条小红书图文，确认按顺序下载且打开图文入口。
2. 用一段短 MP4 和封面建一条小红书视频，确认可以分别下载并打开视频入口。
3. 在测试账号或平台支持的草稿场景选择两类素材，校对字段回读、话题和封面。仅在已获授权时提交真实作品。
4. 发布后验证实际作品链接能回填，刷新工作台后查看归档和操作记录。还在审核和定时时保持待回填。
